## 3. 时间权重口径：三个候选，回测选一个

三个候选口径其实是同一族里的三个点，扫半衰期就同时评了三个版本：

```
w(Δt) = exp(-ln2 · Δt / HL) × tier_weight
```

两个样本外测试集，训练集一律严格早于测试局：

- **A** — TI2026 小组赛 109 场 / 44 系列赛。最贴近的目标人群，但赛前没有任何本赛事
  数据，评不了「只用本赛事」那一版。
- **B** — 六个近期 LAN（PGL Wallachia S8 / DreamLeague S29 / BLAST SLAM VII /
  石油杯 EWC / 1win Essence II / TI 小组赛）各自按时间中位数切开，测后半程，
  共 360 场 / 158 系列赛。训练集含本赛事前半 —— **这才是预测淘汰赛的真实处境**，
  也是唯一能回答「本赛事数据值多少」的实验。

基线 = 生产模型 HL=150。配对检验只在两个口径都评得了的系列赛上做，SE 按赛事聚类。

测试集 A（44 系列赛，噪声大）方向一致但分辨不出：HL 21–400 之间的系列赛 logloss
全在 0.524–0.536，HL=30 是 0.5237、HL=150 是 0.5314；只有 HL≤14 明显更差。

**三个结论**

1. **「只用本赛事」明确最差**，而且差一个数量级的距离。109 场里每队只有 10–17 场，
   评级噪声压过信号。作为额外特征堆叠进长期评级里同样没有增益（−0.0080）。
2. **指数衰减胜出，最优半衰期 21–50 天**。换算成 `e^{-T/τ}` 是 τ ≈ 30–72 天。
3. **硬截断窗口输给指数衰减**（45 天窗口 −0.047），**全历史等权输给 150 天**
   （−0.0060, t=−1.66）。两端都不对，中间有真实的最优。

72 格联合网格（HL ∈ {21,30,40,50,60,80} × l2_team ∈ {0.1,0.3,1.0} ×
选手项 HL ∈ {30,60,150,∞}）整片平坦，好的区域全在 0.567–0.576。**取平台中心
HL=30、其余超参保持生产默认**，不取网格最小值点（HL=30/l2t=1.0/选手HL=60，
0.5672）—— 那是在 72 个格子上挑冠军，必然乐观。

### 3.1 这和 `04-final.md` §3 的负结果冲突，两个都是对的

旧文档记的是「近期比赛 2× / 4× 加权全都变差」。差异是真的，也可解释：

| | 旧实验 | 本次 |
|---|---|---|
| 加权方式 | 在 HL=150 之上给近期比赛乘 2×/4×（不连续） | 直接改半衰期（连续） |
| 测试集 | 泛职业池，月度不重叠窗口 | 赛事后半程 |
| 被测队伍近 30 天的比赛量 | 稀疏，很多队有长空档 | 密集，且是同一批对手 |

**结论限定在赛中预测**：队伍在最近一个月里打了大量与测试局直接相关的比赛时，
短半衰期才有价值。生产评级 `data/ratings_v3.json` 维持 HL=150 不变。

### 3.2 诚实的显著性

HL=30 相对 HL=150 的改善是 **+0.0122 系列赛 logloss，t = +1.29**，
**没有达到显著**。支持这个选择的是两点：方向在两个独立测试集上一致，
以及整个 21–50 天邻域都优于基线（不是单点侥幸）。

### 3.3 后来这个选择被推翻了

上面两个测试集都有一个共同缺陷：**测试集里混着断点前和断点后的比赛**，而我们要预测
的全是断点之后的。§7.3 用只含断点后系列赛的测试集 + 完整生产模型重跑，结论反过来：

| 队伍半衰期 | 系列 logloss | 系列准确 | Δ vs 150天 | t |
|---|---:|---:|---:|---:|
| **30 天** | **0.6721** | 66.2% | −0.0167 | −1.19 |
| 45 天 | 0.6578 | 66.2% | −0.0025 | −0.24 |
| 60 天 | 0.6546 | 66.2% | +0.0008 | +0.10 |
| 150 天 | 0.6553 | 65.5% | 0 | — |

**HL=45 相对 HL=30 是 +0.0143，t = +2.76**，达到显著；HL=30 是四个里最差的。
45 / 60 / 150 互差 ≤0.0025（t ≤0.24），分不出优劣。

原因是**队伍半衰期和选手半衰期不能各自独立地调**：选手项固定在 HL=150（长记忆），
队伍项再压到 30 天就是重复吃同一段近期数据、放大噪声。§3 那个只扫队伍半衰期的实验
看不到这层交互 —— 它在选手项缺席或固定时才成立。

**采用 HL=45**：45 和 60 在断点后测试集上并列最好且给出同一套填法，而 45 在原来的
测试集 B 上也仍在好的区域（0.5770 vs HL=150 的 0.5848）。HL=150 只在前者好、后者差。
45 是唯一不依赖哪个测试集偏爱的选择。

## 5. 计分口径的歧义：算了两种，结论是不重要

本地化只写 `pick the team you think is going to win each series`，没说清楚
「我选的队从另一条路走到这个节点并赢了」算不算对。两种建模：

- **loose** — 只看该节点的实际胜者是不是你选的队，对手是谁、怎么走到那里的都不管。
- **strict** — 还要求该节点的对阵双方也和你预测的一致（整条路径都对）。

两种口径下界面的**约束是一样的**：你只能从自己填法送到该节点的两支队里选。

交叉评估（HL=30 + bootstrap）：

| 填法 | loose 下 | strict 下 | 各半平均 |
|---|---:|---:|---:|
| loose 最优 | **3,659** | 2,048 | **2,854** |
| strict 最优 | 3,525 | **2,084** | 2,804 |

- 押 loose 最优、真实规则是 strict：亏 36 分（**1.7%**）
- 押 strict 最优、真实规则是 loose：亏 134 分（3.7%）
- 「两种规则各 50%」的混合最优 **就是 loose 最优**

**所以这个歧义不需要解决，直接用 loose 最优。** 两套填法只差 3 个节点
（LB1-1、LB2-1、LB3），全在败者组深处、本来就接近五五开。

## 6. 优化：精确枚举，不用模拟

填法空间和结果空间是同一个集合 —— 每个节点二选一，2^14 = **16,384** 种完整对阵树。
所以既能穷举全部候选填法，也能对每种真实结果算出精确概率，`E[得分]` 是一个
16,384 × 16,384 的精确求和，**没有蒙特卡洛误差**（`scripts/bracket_optimize.py`）。

目标是凸的（第 1 个猜对值 120，第 14 个值 +1,080），所以最大化 `E[得分]` ≠ 最大化
`E[猜对数]`。在 loose 口径下两者恰好给出同一套填法；strict 口径下不同
（差 13 分），凸性确实在起作用，只是幅度小。

bootstrap 积分（对复制样本的结果分布取平均，而不是给每场加同一个常数扰动）会明显
拉低 E[得分]，**但没有改变任何一票**。§8 把这一步推广到跨配置的模型池。

### 6.2 顶部很平

500 模型池上前 6 名的 `E[得分]`：3,206 / 3,205 / 3,200 / 3,170 / 3,168 / 3,168。
第 2 名只差 **1 分**。逐票价值见 §8.1：整份方案的价值集中在胜者组前几场，
败者组深处那几票每票只值几十分甚至个位数。

四种半衰期（30 / 45 / 60 / 150）给出的填法里 **11 票完全相同**，分歧只在
UB-F / LB2-1 / LB-F 这条连锁上。

> **不同模型之间的 `E[得分]` 不能横向比较。** HL=30 报 3,659、HL=45 报 3,460、
> HL=150 报 3,021 —— 更锐的模型在自己的模拟里总是显得更好，这不是精度的证据。
> 可信的比较只有 §3.3 那种样本外 logloss。纯 TI 小组赛版（§附录）报出全场最高的
> 4,312，正是这条规则的反面教材：数据最少的模型对自己最有信心。

## 7. 赛程断点：小组赛的状态，隔几天之后还算不算数

坊间说法是「小组赛到淘汰赛中间那几天会有重大变动」。TI2026 的断点是 8/16 → 8/20，
约 4 天。`scripts/break_effect.py`。

### 7.1 设计

不能直接比「小组赛内的准确率」和「淘汰赛的准确率」—— 淘汰赛只剩强队、对阵更胶着，
准确率天然更低，跟状态衰不衰减无关。所以用**同一个状态评级**打两个测试集：

```
在每个赛事小组赛的前 70% 上拟合「本赛事状态」评级 F
  测试集 A = 该赛事小组赛的后 30%    （距拟合截止 0–2 天，中间无断点）
  测试集 B = 该赛事断点之后的淘汰赛   （距拟合截止 = 断点长度 + 若干天）
```

F 在两个测试集上是同一套参数、同样的噪声水平。再把赛前长期评级 x_prior 作协变量
控制对阵胶着程度，看的是 x_form 的增量系数：

```
logit p = a0 + a1·x_prior + a2·x_form + a3·(x_form × 断点后)
```

两个特征在赛事内部标准化，SE 按赛事聚类。断点由「赛事内最大的比赛间隔」自动识别。

### 7.2 结果：全样本有衰减，大型 LAN 没有

**全部 130 个赛事 / 6,107 局**（含线上联赛、预选赛）：

| 系数 | 估计 | SE | t |
|---|---:|---:|---:|
| x_prior 赛前长期评级 | +0.263 | 0.032 | +8.09 |
| x_form 本赛事状态 | +0.401 | 0.059 | +6.83 |
| **x_form × 断点后** | **−0.170** | 0.072 | **−2.35** |
| x_form × 断点天数 | −0.032 | 0.012 | −2.71 |

看起来坊间说法成立：状态跨过断点掉 42%。**但只看 premium 大型 LAN
（37 个赛事 / 1,768 局）时效应消失**：

| 系数 | 估计 | SE | t |
|---|---:|---:|---:|
| x_prior 赛前长期评级 | +0.292 | 0.056 | +5.22 |
| x_form 本赛事状态 | +0.512 | 0.116 | +4.40 |
| **x_form × 断点后** | **−0.082** | 0.123 | **−0.66** |
| **x_form × 断点天数** | **+0.001** | 0.022 | **+0.04** |

按断点长度分桶（premium）：

| 断点 | 赛事 | 局数 | x_prior | x_form |
|---|---:|---:|---:|---:|
| 断点前对照 | 36 | 679 | +0.241 | **+0.526** |
| 0–1.5 天 | 2 | 106 | +0.191 | +0.240 |
| 1.5–3 天 | 26 | 716 | +0.290 | +0.430 |
| **3–5 天**（TI2026 落在这里） | 8 | 244 | +0.425 | **+0.482** |

断点之后 x_form（+0.425）**仍然大于** x_prior（+0.324）：本赛事状态比长期评级更重要。

解读：全样本的衰减来自低级别线上联赛 —— 那里「间隔 5 天」意味着队伍中间跑去打了别的
比赛、赛程本身就是散的；LAN 上的 3–4 天是受控的休息。

⚠️ **但 premium 子样本的置信区间很宽**（−0.32 到 +0.16），**包含**全样本的点估计。
准确的说法是「大型 LAN 数据里测不到断点效应」，不是「证明了没有」。

### 7.3 历届 TI 的直接检验

TI2023 / 2024 / 2025 的 46 个淘汰赛系列赛（TI2022 被自动断点检测排除 —— 它 231 场里
最大间隔 5.7 天出现在第 219 场，是决赛前而非小组赛→淘汰赛的转换）：

| 口径 | 准确率 | logloss |
|---|---:|---:|
| 只用本届小组赛 | 65.2% | 0.6281 |
| 只用赛前长期评级（HL=150） | 60.9% | 0.6345 |
| **全部数据 HL=30** | **67.4%** | **0.6128** |

46 个系列赛，差异都在噪声量级内，但排序与主分析一致。

同一批赛事上做的半衰期头对头（完整生产模型，534 个断点后系列赛）就是 §3.3 那张表 ——
**这是推翻 HL=30 的证据来源**。

### 7.4 选手层面这个问题不可识别

在单个赛事内部，一支队的五个人每场都是同一批，所以「选手级本赛事状态」和「队伍级本
赛事状态」完全共线，回归里分不开。上面的系数已经把两者合在一起测了。

能分开测的是**选手个人产出**（GPM / 击杀 / 补刀等梦幻计分项）跨断点是否稳定，那是
另一个问题，需要历史选手逐场数据（`player_matches.json` 目前只覆盖 TI2026 这 84 人）。
它服务的是梦幻挑战，对淘汰赛填法没有影响。

## 8. 模型池积分：把配置不确定性也算进去

45 / 60 / 150 三个半衰期在断点后测试集上分不出优劣（两两 ≤0.0025，t ≤0.24），但它们
给出的填法在 3 个节点上不一致（UB-F / LB2-1 / LB-F，全是「TY vs FLCN 谁赢」的连锁）。

拿三个点估计手工取平均是糊的。正确做法是把三个配置的 bootstrap 复制样本合并成一个
模型池 —— 池里既有参数不确定性（同一配置内重抽样），也有配置不确定性（跨半衰期）——
然后在这个池上求 E[得分] 的 argmax。`scripts/bracket_model_average.py`。

**500 个概率模型（HL=45 ×200 + HL=60 ×150 + HL=150 ×150）的池上，已提交的这套填法
就是 argmax：16,384 套里排第 1，落后 0 分。**

### 8.1 每一票值多少分

翻掉某一票、下游允许跟着重排、其余节点不动，期望分的变化：

| 节点 | 填法 | 翻这一票的代价 |
|---|---|---:|
| UB-B | Team Vision | **−1,271** |
| UB-E | Team Vision | −660 |
| UB-D | Team Falcons | −508 |
| GF | Team Vision | −404 |
| UB-C | Team Yandex | −262 |
| UB-G | Team Vision | −262 |
| LB1-2 | Team Liquid | −193 |
| UB-A | Iron Wing | −187 |
| LB2-2 | Iron Wing | −99 |
| LB-F | Team Falcons | −70 |
| LB3 | Iron Wing | −38 |
| LB1-1 | BoomBoys | −37 |
| **LB2-1** | Team Yandex | **−6** |
| **UB-F** | Team Falcons | **−2** |

价值高度集中在**胜者组前几场**：光 UB-B（Vision 打 BoomBoys，88%）一票就值 1,271 分，
而争议最大的 UB-F 值 2 分。败者组深处那五票加起来不到 UB-B 一票的四分之一。

### 8.2 本轮最值得记住的一条：模型选择 ≠ 方案选择

半衰期这件事上，**log-loss 是选模型的正确判据，而且它给出了显著的结论**
（HL=45 优于 HL=30，t=+2.76）。这个结论成立，以后默认配置就用它。

但**方案该不该改，要另外算一次期望分**。把 HL=30 与 HL=45 各自的最优填法放到四个概率
模型下交叉评估：

| 概率来源 | HL=30 填法 | HL=45 填法 |
|---|---:|---:|
| HL=30 | **3,793** | 3,737 |
| HL=45 | 3,456 | **3,460** |
| HL=60 | 3,309 | **3,317** |
| HL=150 | **3,021** | 2,996 |

模型精度的提升，只有落在**会改变 argmax 的节点**上才转化为分数。这里它几乎全部消耗
在一个 49.9%–52.0% 的节点上（§4.1），于是 14 票里 11 票不动，剩下 3 票值 ±5 分。

**两个判据都要用，不能互相替代**：只看 log-loss 会做出无意义的改动；只看期望分会
永远不更新模型。中间过程里我犯过的错是把已经判定为最差的 HL=30 也放进交叉评估的平均
里当论据 —— 既然认定它差，就不该拿它的概率给方案打分。剔掉之后结论不变（3,262 vs
3,258），但理由才是对的。

## 11. 代码

| 脚本 | 作用 |
|---|---|
| `topup_matches.py` | 增量补拉 rich / lineups / player_matches，按 id 去重；`--since/--until` + 按月分片可回补历史 |
| `ti_results.py` | 从 `GetLeagueData` 解赛果 + 14 节点对阵树 → `ti2026_bracket.json` |
| `weighting_backtest.py` | 时间权重口径的两个样本外测试集，`--sweep` 联合网格 |
| `break_effect.py` | 断点效应回归；`--hl-sweep` 专测断点后的半衰期 |
| `postbreak_headtohead.py` | 完整生产模型 + 只测断点后系列赛的半衰期头对头（推翻 HL=30 的那个实验） |
| `fit_playoff_probs.py` | 按指定半衰期重拟合 + Poisson bootstrap → 8 队胜率矩阵 |
| `bracket_optimize.py` | 16,384 套填法 × 16,384 种结果的精确枚举，两种计分口径 |
| `bracket_model_average.py` | 多配置 bootstrap 合池、逐票价值、方案排名 |

复现：

```bash
python3 scripts/topup_matches.py --since 2022-01-01 --until 2025-01-01   # 回补历史
python3 scripts/topup_matches.py --since 2026-08-01                      # 补到最新
python3 scripts/ti_results.py
python3 scripts/weighting_backtest.py                       # 第一轮选口径
python3 scripts/break_effect.py --premium --min-games 40     # 断点效应
python3 scripts/postbreak_headtohead.py --premium            # 半衰期头对头（决定性）
for hl in 45 60 150; do
  python3 scripts/fit_playoff_probs.py --hl $hl --player-hl 150 --boot 200 \
          --out data/playoff_probs_hl$hl.json
done
python3 scripts/bracket_model_average.py data/playoff_probs_hl{45,60,150}.json
```
