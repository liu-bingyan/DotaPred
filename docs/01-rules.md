### 2.1 小组赛预测：把 16 支队伍放进 6 个筐

| 分类 | 名额 | 说明 |

| **0-4** | 1 | 一支全败的队伍 |

⚠️ 这是**强约束的排列问题**，不是 16 个独立二元预测。名额固定 → 必须做全局最优分配，不能逐队贪心。

## 3. 梦幻挑战（Fantasy）

### 3.1 阵容构成（2026 改版）

选 **3 支队伍**，不是选 5 个人：

| 槽位 | 内容 |
|---|---|
| 核心 | 某队的**双人组**（1 号位 + 3 号位），两人都计分 |
| 中单 | 某队的中单（单人） |
| 辅助 | 某队的**双人组**（4 号位 + 5 号位），两人都计分 |

两个结算期（小组赛 / 国际邀请赛）各自锁定阵容，可分别调整。

### 3.2 战旗 / 徽标系统

- 每个槽位有一面**战旗（War Banner）**，由若干**徽标（Emblem）**组成。
- **只有战旗上存在的统计项才计分** —— 这是核心机制：你在为自己选中的选手「定制计分项」。
- 徽标颜色决定它能对应哪些数据：

| 颜色 | 可对应的数据 |
|---|---|
| 🔴 红 | 击杀、死亡、正反补、GPM、狂石收集数量、摧毁防御塔 |
| 🔵 蓝 | 放置假眼、堆叠野怪、拾取神符、占领观察者、使用诡计之雾、采集莲花 |
| 🟢 绿 | 击杀肉山、参与团战、眩晕、消灭痛苦魔方、第一滴血、杀害信使 |

- **徽标品质加成**：1 阶 +10% / 2 阶 +30% / 3 阶 +60% / 4 阶 +100% / 5 阶 +150%
- **徽标特性**：
  - 分形：战旗上所有徽标品质互不相同 → 该项 +60%
  - 仁爱：给**相邻**徽标 +20%
  - 吸血鬼：自身 +50%，相邻徽标各 −10%
  - 唯一：若是战旗上唯一的「唯一」徽标 → +30%
  - 友好：战旗上有 ≥3 个「友好」徽标时 → +50%
- **重新生成（Roll）**：每次有 3 个生成选项（对所有战旗相同），每次消耗 1 枚重选代币，只影响当前战旗，使用后替换所有选项。战旗上的统计数据不会重复。

### 3.3 指导员称号（Coach Titles，2026 新增）

给**自己**选前缀 + 后缀，满足条件时对**全队所有选手**的最终积分提供百分比加成。免费随时更改（不消耗代币）。
已知前缀条件示例（来自本地化文件）：使用红/蓝/绿英雄、有角或翅膀的英雄、水/火/冰系英雄、亡灵/恶魔/精魂英雄、有胡子或毛茸茸的英雄。

### 3.4 计分流程

```
每场比赛，每位选手单独结算（只算战旗上有的项，再乘徽标品质/特性/称号加成）
  → 同一槽位内两名选手取平均 = 该场该槽位得分
  → 一个系列赛内取得分最高的 2 场
  → 若该槽位在一个结算期打了多个系列赛，取得分最高的那个系列赛
```
