# 迭代结果：准确率能到哪，以及 75% 为什么不可能

> 2026-07-31 夜间自主迭代。**本文的评级与方案取代 `02-model.md`、`03-margin.md`。**

## 0. 结论先行

| | 达成 | 目标 |
|---|---:|---:|
| 单场准确率（封存 holdout） | **62.0%** | 75% |
| BO3 系列赛准确率（封存 holdout） | **65.3%** | — |
| TI16 赛场上的 BO3 预期准确率 | **约 71–72%** | — |

**75% 的单场准确率不可能达到**，我有硬证据（第 2 节）。但在 TI16 这个具体赛场上，BO3 层面接近 70% 是现实的 —— 因为 TI 的实力跨度比一般职业池大，且 BO3 会放大区分度。而 BO3 恰好就是预测活动实际需要的粒度。

## 2. 为什么 75% 不可能：先知实验

用**包含测试局本身**的数据拟合评级（即模型已经知道这些比赛怎么打的），几乎不正则化。它的样内准确率是任何「用标量表示队伍强度」的模型的**严格上界**：

```
先知模型（无时间衰减，l2=0.05）  样内准确率 = 64.97%
先知模型（二值目标，l2=0.01）    样内准确率 = 65.18%
E[max(p, 1-p)]                              = 65.2%
预测概率分布：p10=0.27  p50=0.52  p90=0.76
```

**一半的顶级职业局，真实胜率在 0.5 附近。** 这不是模型不够好，是比赛本身就接近抛硬币。要突破 65%，需要赛前拿不到的信息（BP、当日状态、临场发挥）。

我的 62.0% 距离这个 65.2% 的天花板只剩 3.2 个百分点。

### 2.1 但 TI16 是特例

TI16 的 120 组对阵中，模型隐含的准确率上限：

| | 隐含上限 |
|---|---:|
| 单场 | 68.0% |
| **BO3** | **74.5%** |

比一般职业池高，因为 TI 的实力跨度大（Vision 到 Resilience）。holdout 上模型过度自信约 2.3 个百分点，套用同样的修正，**TI 的 BO3 实际准确率预期在 71–72%**。

## 3. 试过的所有东西（含全部否定结果）

在 SELECT 切点上测试，基线 = 队伍级 gdpm 评级（59.60%）：

| 尝试 | log-loss | 准确率 | 结论 |
|---|---:|---:|---|
| 队伍级评级（基线） | 0.6704 | 59.60% | — |
| **+ 选手级评级（l2=30）** | **0.6658** | **60.23%** | ✅ **采用**（t=2.51） |
| 选手级单独用 | 0.6750 | 57.74% | ❌ 比基线差 |
| 分阶段评级（对线/中期/后期） | 0.6716 | 59.11% | ❌ **变差** |
| 队伍+选手+分阶段 | 0.6686 | 59.86% | ❌ 不如只加选手 |
| 联合拟合（队伍+选手同时估） | 0.6705 | 58.75% | ❌ 无增益 |
| 多时间尺度（60/150/400 天） | 0.6706 | 59.46% | ❌ 无增益 |
| 近期比赛 2× 加权 | 0.6715 | 59.28% | ❌ 变差 |
| 近期比赛 4× 加权 | 0.6753 | 58.73% | ❌ 更差 |
| 兵营差作目标 | 0.6753 | 58.67% | ❌ 比胜负还差 |
| 手工 5 分量复合指标 | 0.6701 | 59.00% | ❌ 输给单一 gdpm |

**七个想法里六个失败。** 有价值的负结果：

1. **分阶段评级失败** —— 我以为「前期强后期弱」能建出克制关系，结果加 3 个相关特征就是过拟合。
2. **加权近期比赛全都变差** —— 150 天半衰期已最优。「状态」没有「实力」重要，这与直觉相反。
3. **联合拟合输给两模型堆叠** —— 更"正确"的统计结构没有回报。
4. **手工复合指标输给单一特征** —— 你提醒的过拟合风险是真的。

这些一致地指向：**这份数据只支持简单模型**。最终模型只有 2 个特征。

### 3.1 一个重要的正面确认

BO3 内的比赛**可以当作独立事件**。经验拟合 `logit(P_系列) = 1.485 × logit(p_单场)`，独立性理论隐含 1.51，几乎重合。这验证了模拟器里用的 `p²(3−2p)` 是对的 —— 我原本担心它高估了确定性，事实上没有。

| | v1 胜负 | v2 经济差 | **v3 队伍+选手** |
|---|---:|---:|---:|
| E[猜对数] | 5.61 | 6.01 | **6.56** |

「按实力排序即最优」的结论在三个版本中都成立（重排不等式，与评级来源无关）。
